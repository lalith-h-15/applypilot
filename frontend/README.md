# ApplyPilot frontend

ApplyPilot is a React single-page app built with Vite, Tailwind CSS, and React
Router. The dashboard currently uses mock API data; set `VITE_API_URL` to point
the client at a backend API.

## Development

```sh
npm install
npm run dev
```

Create a production build with `npm run build`. The generated `dist/` directory
is ignored by Git.
